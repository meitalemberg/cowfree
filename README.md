# הקפוצ'ינו שלא היה אמור להזיק

חדר בריחה מדעי של 30 דקות על חלב ללא פרה, לכיתה י׳. אפליקציית ווב לטלפון (צוות = טלפון אחד) ומסך מורה למחשב או למקרן.

האפיון המלא: [docs/SPEC.md](docs/SPEC.md).

## הרצה

צריך רק Python 3 (מותקן בכל Mac). אין התקנות ואין שלב בנייה.

```bash
python3 server.py
```

- **מסך מורה:** <http://localhost:3000/teacher>
- **תלמידים:** סורקים את קוד ה-QR שבמסך המורה, או נכנסים לכתובת שמודפסת בטרמינל (למשל `http://192.168.1.20:3000`) ומקלידים את קוד השיעור.
- **מצב תרגול:** כניסה ל-<http://localhost:3000> בלי קוד שיעור מריצה את המשחק לבד, בלי מורה.

הטלפונים והמחשב צריכים להיות על אותה רשת Wi-Fi. ברשת בית ספרית שחוסמת תקשורת בין מכשירים, אפשר לפתוח נקודה חמה מהטלפון של המורה, או להעלות את התיקייה לשרת שמריץ Python.

פורט אחר: `PORT=8080 python3 server.py`

## מהלך שיעור

1. במסך המורה: **שיעור חדש**. מקרינים את קוד ה-QR.
2. הצוותים בוחרים שם וסמל, קוראים את שיחת הוואטסאפ, את המחלוקת ואת מכתב המשימה.
3. **התחילו משחק**: הכפתור "פתחו את התיק" נפתח בכל הטלפונים, והטיימר של כל צוות מתחיל כשהוא לוחץ.
4. בלשונית **לוח צוותים** רואים עמדה, זמן, רמזים וקודים שגויים. צוות שתקוע יותר מ-7 דקות מסומן בענבר, ואפשר לדלג לו על עמדה.
5. אחרי פסקי הדין: **מסכי הטוויסט** (מעבירים בחיצים במקלדת). בשקף השלישי נפתחת הצבעה בטלפונים.
6. **שחרור כרטיס יציאה**, ובסוף **ייצוא CSV** ו**איפוס שיעור**.

## הקודים

הפתרונות רשומים באפיון. בקוד האתר נשמר רק גיבוב SHA-256 שלהם (`HASHES` ב-`public/js/content.js`), כך שהם לא מופיעים ב"הצג מקור". כדי לשנות קוד, מחשבים גיבוב חדש:

```bash
python3 -c "import hashlib;print(hashlib.sha256('cowfree-0418:1:132'.encode()).hexdigest())"
```

המבנה הוא `cowfree-0418:<מספר עמדה>:<הקוד בלי רווחים ומקפים, באותיות קטנות>`.

## מבנה

| קובץ | תפקיד |
|---|---|
| `server.py` | שרת: קבצים סטטיים, שיעורים, סנכרון ופקודות מורה. שומר ל-`data/sessions.json` |
| `public/index.html`, `js/app.js` | אפליקציית הצוותים: מסכים, עמדות, טיימר, שמירה במכשיר |
| `public/teacher.html`, `js/teacher.js` | מסך המורה |
| `public/js/content.js` | כל הטקסטים, הרמזים, טבלת הקוד הגנטי ונתוני הג'ל |
| `public/js/art.js` | האיורים (SVG) |
| `public/js/hash.js` | SHA-256 שעובד גם בדף http ברשת מקומית |
| `public/vendor/qrcode.min.js` | ספריית qrcode-generator (MIT) ליצירת קוד ה-QR |

## מה להתאים לפני שיעור

- **תמונת התווית** לשקף הראשון של הטוויסט: מעלים ממסך המורה. היא נשמרת רק בדפדפן הזה.
- **רשימת הרכיבים** בשקף השני היא דוגמה גנרית. מחליפים ב-`INGREDIENTS` שבראש `public/js/teacher.js` לפי התווית האמיתית.
- **טקסטים**: הכול ב-`public/js/content.js`.

## פרטיות

נשמרים רק שם צוות, סמל, התקדמות ותשובות. אין הרשמה, אין שמות תלמידים ואין מעקב. שיעור נמחק מהשרת אחרי 24 שעות. הגופנים נטענים מ-Google Fonts; בלי אינטרנט האפליקציה עובדת עם גופני המערכת.
